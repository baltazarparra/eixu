# Projeto Premium raizenbank

Este app pertence à EIXU e atende https://raizenbank.eixu.com.br. Edite e valide dentro desta pasta. O gerador não mantém mais a implementação.

- npm run typecheck
- npm run lint
- npm run build

Mantenha EIXU_PREMIUM_TOKEN apenas no ambiente da Vercel. Leads, eventos e WhatsApp passam pelas rotas server-side locais para a plataforma central.
